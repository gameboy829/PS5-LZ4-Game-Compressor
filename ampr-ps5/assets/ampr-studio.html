Help
1. Close the game, select it, then mount it.
2. Choose where to save the new game and check the plan.
3. Start conversion. Packing and selected checks have separate progress and time estimates. Conversion options control verification and what happens to the original.
The estimate describes the current stage. It updates as more data is processed.
Workflow inspiration: Game Compressor — juma-sayeh, Lazy_AMPR — Nazky, ampr_emu — drakmor, and LZ4 — Yann Collet and contributors.
Controller: arrows / D-pad move between controls. Left and right change a focused choice. Cross selects; Circle returns. Keyboard: Tab, Enter and Escape.


Performance details
Median-speed run shown. Wait counters settle on wakeup; queues are snapshots. Read/write speed includes cache effects. Full measurements and findings are in the report.
